# AI-Autonomous-Drone
## Overview
This project aims to design and build an autonomous drone capable of navigating its environment using artificial intelligence and computer vision.
The project combines hardware, software, and machine learning to create a drone that can detect obstacles, make navigating decisions, and fly autonomously.
--
## Project goals 
-Build an autonomous drone 
Detect obstacles using AI
Navigate without human input 
Process camera images in real time 
Develop a scalable AI system for future improvements
